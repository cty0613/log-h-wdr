# 고정소수점 규칙 (H-Log LUT)

`core/include/cctvlog/fixed.hpp`, `core/include/cctvlog/curves.hpp`(`FixedLut`)와 항상 일치해야 한다. 확정: 2026-11-22 (Phase 3, decisions.md 결정 5).

## 1. 반올림·포화 (`fixed.hpp`)
- 반올림: round-half-up = floor(v + 0.5). 음수도 같은 식(−0.5 → 0, −1.5 → −1).
- 포화: [lo, hi]로 자른다. NaN은 lo.
- 정규화 신호 V → bits 코드: `to_code(V, bits) = quantize(V·(2^bits − 1), 0, 2^bits − 1)`.

## 2. 정방향 LUT
- 입력 정의역: [0, x_max]. 밖은 포화(x < 0 → 0, x > x_max → x_max). NaN → 인덱스 0.
- 인덱스: `i = quantize(clamp(x)/x_max · 65535, 0, 65535)` (65536 엔트리, x에 대해 균등).
- 엔트리: `to_code(C(i/65535·x_max), 10) << 6` (uint16, 상위 10 bit 유효, 하위 6 bit 0).
- 조회: `code10 = forward[i] >> 6`. 보간 없음.

## 3. 역방향 LUT
- 1024 엔트리: `float32(C⁻¹(code / 1023))`. 범위 밖 코드는 [0, 1023]으로 자른다.

## 4. 오차 표 (수락 기준: 10 bit 기준 최대 1 LSB)
float 기준 코드는 `to_code(C(x), 10)`(float 경로를 같은 규칙으로 양자화한 값)이다. 1 LSB 오차는 인덱스 반올림(최대 반 칸)이 출력 코드의 반올림 경계를 넘길 때만 생긴다. 반 칸이 1 LSB보다 작으므로(x = 0에서 최대 0.91 / 2 = 0.45 LSB) 2 LSB 이상은 생길 수 없다.
