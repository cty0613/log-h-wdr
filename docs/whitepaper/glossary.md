# 부록. 용어집

가나다·알파벳 혼합으로, 분야별로 묶었다. 괄호 안은 처음 나오는 장.

## 빛과 센서
| 용어 | 설명 |
|---|---|
| 광자 (2) | 빛의 알갱이. 센서는 광자가 만든 전자를 센다 |
| 양자 효율, QE (2) | 광자 하나가 전자 하나를 만들 확률 |
| full well (2) | 화소가 담을 수 있는 최대 전자 수 |
| 전환 이득 (2) | 전자 1개가 만드는 전압. 플로팅 디퓨전의 커패시턴스로 정해진다 |
| 아날로그 게인 (2) | ADC 전 증폭. ISO에 해당. IMX708은 1.1228~16 |
| ADC (2) | 전압을 정수로 바꾸는 회로 |
| DN (2) | ADC가 낸 정수 값 하나(Digital Number) |
| 블랙 레벨 / 페데스탈 (2) | 빛이 없을 때의 의도적 오프셋(10bit 64). 음수 노이즈 보존용 |
| 화이트 레벨 (2) | 포화 값(10bit 1023) |
| Bayer 필터, CFA (2) | 화소마다 R/G/B 중 한 색만 통과시키는 필터 배열 |
| 쿼드 베이어 (2) | 같은 색 화소가 2×2로 모인 배열(IMX708) |
| Bayer 순서 (2) | 2×2 패턴의 시작 순서(RGGB, BGGR …) |
| 롤링 셔터 (2) | 행마다 시간을 조금씩 밀어 노출하는 방식 |
| RAW (2) | ISP 처리 전 센서 값. 선형 |
| 비네팅 / 렌즈 셰이딩 (6) | 렌즈 가장자리가 어두워지는 현상 |

## 노이즈와 측정
| 용어 | 설명 |
|---|---|
| 샷 노이즈 (3) | 광자 도착의 무작위성. 분산 = 평균(포아송) |
| 판독 노이즈 (3) | 회로에서 생기는 일정한 노이즈 |
| 고정 패턴 노이즈, FPN (3) | 화소마다 고정된 감도·오프셋 차이(PRNU, DSNU) |
| 양자화 노이즈 (3, 5) | 정수 반올림 오차. 표준편차 Δ/√12 |
| PTC (3) | Photon Transfer Curve. 평균 대비 분산 그래프 |
| 쌍 차분 (3) | 두 프레임의 차이로 시간적 노이즈만 구하는 방법 |
| K (3) | DN/e⁻. PTC 기울기 |
| a, b (3) | 정규화 노이즈 모델 σ²(x) = a·x + b의 계수 |
| SNR (3) | 신호 / 노이즈 |
| DR (1, 3) | 다이내믹 레인지. 포화 신호 / 바닥 노이즈 |
| stop, EV (3) | log₂ 비율. 1 stop = 2배 |
| dB (3) | 20·log₁₀ 비율. 약 6 dB = 1 stop |
| EMVA 1288 (3) | 머신비전 카메라 특성 측정 표준 |
| 플랫필드 (3) | 화면 전체가 균일한 밝기인 촬영 |
| 다크 프레임 (3) | 빛을 완전히 막고 찍은 프레임 |
| MTF50 (6) | 대비가 50%로 떨어지는 공간 주파수. 선명도 지표 |
| 변환 이득 (3) | 1 DN에 해당하는 전자 수(e⁻/DN). K의 역수 |
| ROI (3) | 분석에 쓰는 영역(Region of Interest). 이 프로젝트는 중앙 256×256 |
| 행 노이즈 (3) | 한 행 전체가 함께 흔들리는 노이즈. 행 평균의 분산으로 잰다 |
| blooming (3) | 포화된 화소에서 넘친 전하가 이웃 화소로 번지는 현상 |
| brighter-fatter (3) | 전하가 많이 쌓일수록 이웃으로 퍼져, 밝은 쪽에서 분산이 직선보다 덜 커지는 효과 |
| PWM 깜빡임 (2, 3) | LED를 빠르게 켰다 껐다 해서 밝기를 조절하는 방식. 롤링 셔터에서 가로 줄무늬가 된다 |
| 감시 타이머 (9) | 일정 시간 안에 진행이 없으면 상태를 남기고 프로그램을 끝내는 장치 |

## HDR
| 용어 | 설명 |
|---|---|
| DR 확보 (1) | 물리적으로 범위를 넓히는 것(브래킷, DCG) |
| DR 보존 (1) | 확보한 범위를 저장 시 버리지 않는 것(곡선) |
| 브래킷 (4) | 노출을 바꿔 여러 장 찍기 |
| 노출비 R (4) | t_long / t_short |
| 포화 임계 τ (4) | 긴 노출을 쓸지 정하는 기준(0.9) |
| 경계 띠 (4) | 두 노출을 섞는 구간 [0.8τ, τ] |
| SNR dip (4) | 합성 경계에서 SNR이 떨어지는 현상. ≈ 10·log₁₀R dB |
| 출처 맵 (4) | 화소별로 어느 노출에서 왔는지 기록한 맵 |
| DCG (4) | Dual Conversion Gain. 한 화소를 두 전환 이득으로 읽기 |
| HCG / LCG (4) | 고 / 저 전환 이득 판독 |
| 몬테카를로 (4) | 무작위 표본을 많이 뽑아 통계로 검증하는 방법 |
| 고스트 (4) | 브래킷 사이 움직임으로 생기는 겹침 |
| 합성 후 노이즈 분포 (4) | 구간별 σ²(x) = aᵢx + bᵢ (5.4 스키마) |
| 센서 HDR 모드 (3, 4) | 센서 안에서 여러 노출을 합성해 압축된 값으로 내보내는 모드. 이 프로젝트에서는 비교군 |
| 유효 노출 (3) | 게인 × 노출 시간. 게인을 바꿔도 같은 응답이 나오는지 확인하고 썼다 |
| 입력 기준 SNR (3) | 압축된 출력의 노이즈를 응답 기울기로 나눠 장면 단위로 되돌린 SNR |
| 꺾은선 압축 (3) | 구간마다 기울기가 다른 직선으로 값을 줄이는 방식(piecewise linear companding) |
| BIC (3) | 모델 복잡도에 벌점을 주어 구간 수 같은 선택을 하는 기준 |

| 용어 | 설명 |

| N (5) | ∫dx/σ(x). 1σ 간격으로 구분 가능한 단계 수 |
| 필요 비트 (5) | ⌈log₂N⌉ |
| 분산 안정화 변환 (5) | 노이즈 크기를 값과 무관하게 만드는 변환(예: Anscombe) |

| HLG (5) | Hybrid Log-Gamma, HDR 방송 표준(BT.2100) |
| S-Log3 (5) | Sony 시네마 카메라 Log 곡선 |
| LUT (5) | 미리 계산한 표(Look-Up Table) |
| 고정소수점 (5) | 소수를 정수로 표현하는 방식 |
| LSB (5) | 출력 코드 1단계. 10bit에서 1/1023 |
| round-half-up (5) | 0.5를 위로 올리는 반올림 |
