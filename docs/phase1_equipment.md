# Phase 1 촬영 준비물과 배치

Phase 1 PTC(Photon Transfer Curve) 촬영에 필요한 준비물, 배치, 촬영 당일 절차를 정리한다.
원리 설명은 [기술백서 3장](whitepaper/03_noise_and_ptc.md)에 있다.

**핵심 요구사항 두 가지**
1. **깜빡이지 않는 광원**: PWM 디밍 광원은 롤링 셔터와 만나 프레임 안에 가로 줄무늬를 만든다. 줄무늬는 노이즈 분산을 부풀린다.
2. **빛이 새지 않는 차광**: 다크 프레임에 빛이 섞이면 read noise와 블랙 레벨이 틀어진다.

광원 균일도는 생각보다 덜 중요하다. PTC는 프레임 쌍의 차분과 중앙 ROI로 계산하므로, 완만한 밝기 기울기는 차분에서 대부분 사라진다.

## 1. 균일 광원

### 1.1 광원: A4 LED 트레이싱 패드(라이트박스) 1개

| 항목 | 조건 | 이유 |
|---|---|---|
| 크기 | A4 이상 | Camera Module 3 **Wide**는 대각 화각이 약 120°다. 렌즈를 패드 가까이 대도 화면 전체가 빛으로 차야 한다 |
| 전원 | USB | 전원 노이즈가 적고 Pi 옆에서 쓰기 편하다 |
| 밝기 조절 | 무단 또는 3단 이상 | 밝기를 대략 맞추는 데만 쓴다(1.3절) |
| **깜빡임** | "플리커 프리" 표기, 또는 1.4절 테스트 통과 | 싼 제품은 낮은 밝기에서 PWM으로 깜빡인다 |
| 가격 | 1~3만 원 정도 | |

- 대안: 플리커 프리 표기가 있는 사진·영상용 LED 패널. 비싸지만 깜빡임 걱정이 거의 없다.
- **사용 금지**: 천장 형광등·LED 조명. 국내 전원은 60 Hz라 조명이 120 Hz로 깜빡인다. 촬영 중에는 실내 조명을 끈다.

### 1.2 확산판: 오팔(유백색) 아크릴 2~3 mm, 10×10 cm 정도
- 아크릴 판매점에서 "유백 아크릴"로 찾는다. 몇천 원.
- 없으면 흰 복사지 2~3장을 겹쳐 쓴다. 종이 결이 보일 수 있다.

**배치 (옆에서 본 모습)**
```
 [Pi 카메라]|렌즈|[확산판]   <- 3~10 cm ->   [트레이싱 패드]
             ^ 밀착                          (발광면이 카메라 쪽)
   주변은 검은 종이 통 / 검은 테이프로 감싸 측면 빛 차단
```
- 확산판을 렌즈에 **밀착**한다. 초점이 완전히 흐려져서 패드의 얼룩·먼지가 보이지 않는다.
- 측면에서 들어오는 빛은 검은 종이 통이나 테이프로 막는다.

### 1.3 밝기 단계는 노출 시간으로 만든다
- PTC 10단계와 Phase 2 플랫필드 15단계 이상은 **광원을 고정하고 노출 시간만 바꿔** 만든다.
  - 디머 눈금은 재현이 어렵다. 노출 시간은 프레임 메타데이터에 정확히 남는다.
  - 센서 특성 측정 표준(EMVA 1288)도 노출 시간 변경 방식을 허용한다.
- 디머는 게인별로 "가장 긴 노출에서 포화되는 밝기"를 한 번 맞추는 데만 쓴다.
  - 예: 게인 1.1228에서 50 ms 근처가 포화되도록 맞춘다.
  - 같은 밝기에서 게인 16은 약 3.5 ms에서 포화된다(16 / 1.1228 ≈ 14.3배). 그래서 디머를 다시 조절하지 않아도 된다.
- 노출이 짧을수록 라인 단위 양자화로 상대 오차가 커진다(1 ms에서 −1.2%, `pi_notes.md` 9절). 실제 노출은 메타데이터 값을 쓴다.

### 1.4 깜빡임 테스트 (구매 전후)
1. **스마트폰 슬로모션**: 패드를 가장 어두운 설정에 두고 찍는다. 줄무늬나 깜빡임이 보이면 탈락.
2. **Pi 카메라 확인 (확실한 방법)**: 노출 100 µs 정도로 찍는다. 롤링 셔터는 행마다 다른 시각에 빛을 받으므로, PWM이 있으면 **가로 줄무늬**로 드러난다. 행 평균을 그려서 주기적인 변동이 없으면 통과한다. → `capture_ptc.py`의 사전 확인 단계에 넣는다.

## 2. 다크 프레임용 차광

Camera Module 3에 맞는 정품 렌즈 캡은 없으므로 직접 만든다.

| 재료 | 쓰는 법 |
|---|---|
| **검은 절연 테이프** (PVC) | 렌즈 위를 2~3겹 덮는다 |
| 알루미늄 호일 | 테이프 위를 한 번 더 감싼다 |
| **암막 천** (두꺼운 검은 천) | 카메라 보드 전체를 덮어 PCB 옆·뒤로 새는 빛을 막는다 |
| 어두운 방 | 조명을 끄고 모니터는 멀리 둔다 |

**차광 확인** (화소값만 보고는 충분한지 알 수 없으므로 두 가지를 비교한다)
- 노출 1 ms와 400 ms의 평균이 같아야 한다. 노출에 따라 평균이 늘면 빛이 새는 것이다.
- 방 조명을 켰을 때와 껐을 때 평균이 같아야 한다.

## 3. 고정 장치

| 항목 | 조건 |
|---|---|
| **카메라 케이스** | 1/4인치(1/4"-20) 삼각대 나사 구멍이 있는 Camera Module 3 호환 케이스(Arducam 등 서드파티). 모듈의 M2 나사 구멍 4개로 직접 고정해도 된다 |
| **삼각대** | 1/4인치 나사, 볼헤드 탁상용 미니 삼각대. 다리가 얇은 셀카봉형은 흔들려서 피한다 |
| 케이블 고정 | Pi 5용 22핀↔15핀 FFC 케이블을 테이프로 책상에 고정해 케이블 장력이 카메라를 움직이지 않게 한다 |
| (선택) 긴 FFC 케이블 | 30~50 cm. Phase 2·5 장면 촬영 때 카메라를 Pi와 떨어뜨려 둘 수 있다 |

- PTC에서는 고정이 덜 중요하다. 확산판을 렌즈에 밀착하면 화면에 구조가 없기 때문이다.
- **Phase 2 브래킷 장면 촬영에서는 중요하다.** 정지 장면 한정이라 세트 안에서 1화소라도 움직이면 합성 경계가 깨진다. 처음부터 단단한 것으로 준비한다.

## 5. 촬영 당일 체크리스트

1. 실내 조명을 끄고 트레이싱 패드를 켠 뒤 **10~15분 예열**한다. LED 출력은 처음 몇 분 동안 온도에 따라 변한다.
2. Pi와 카메라도 몇 분 돌려 센서 온도를 안정시킨다. 프레임 JSON에 `sensor_temperature`가 기록된다.
3. 깜빡임 테스트를 한다(1.4절, 100 µs 가로 줄무늬 확인).
4. 게인별 밝기를 맞추고 플랫필드 쌍을 촬영한다. **촬영 중에는 패드 밝기를 바꾸지 않는다.**
5. 차광한 뒤 다크 10장과 차광 확인 프레임(2절)을 찍는다.
6. 결과 폴더와 `pi_job.json`이 PC로 회수됐는지 확인한다.
